Import an existing repository

Prepare a repository, then push one branch directly from your local Git clone. No archive or bundle is needed.

Only the selected branch and its reachable history are imported—not tags or other branches. Historical authors may be different; new commits must use an email approved for your account.

After import, clone Bastion’s permission-aware view for ongoing work; its commit IDs may differ from the original history. Submodule history is unsupported; external Git LFS objects are not transferred.


        
When Git asks, use username owner and the import credential as your password. This credential expires after one hour and only authorizes the initial push.

        
        
        
        
        
        
A replacement invalidates the previous credential. Never put credentials in the remote URL. Enable credential.useHttpPath so Git distinguishes repositories. After import, replace the cached import credential with normal repository credentials.
